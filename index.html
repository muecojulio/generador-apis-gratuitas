Ajustes de la API (opcionales)

El token se muestra una sola vez al terminar; guárdalo. Si vuelves a generar una API protegida sin marcar la casilla, se le quita la protección. Puedes ajustar los límites de registros, tamaño y retención en estos campos. El archivo de datos no puede pasar de 512 KB.

Clave del taller (opcional)

Si en Vercel definiste la variable GENERADOR_SECRETO, escribe aquí ese mismo valor. Si no la definiste, déjalo vacío: cualquiera que abra la página podrá crear APIs.

Cómo nace

  1. 01Describes tablas, campos y reglas.
  2. 02GitHub Actions escribe api/tu-nombre/spec.json y regenera el registro.
  3. 03Vercel publica /api/tu-nombre con las rutas listas.
  4. 04La documentación queda en /docs?api=tu-nombre y el plano en /api/tu-nombre/openapi.json.

La IA solo devuelve un plano (qué tablas, qué campos, qué reglas). El programa que atiende las peticiones es siempre del taller, revisado y fijo: ningún texto tuyo se convierte en código ejecutable.

Documentación y control

  • Documentación automática generada del plano, con ejemplos y enlace a Swagger.
  • Límite de registros, tamaño y retención configurables por API.
  • Modo solo lectura y autenticación simple por token, sin costo.
  • Fuentes públicas sin clave que normalizan países, monedas y ciudades.
  • Proveedores de IA en orden: primero los que no piden clave y después los que sí.

Vista previa

Mientras escribes, el lector del taller arma las rutas aquí mismo, sin enviar nada a ningún servidor.

Coste

Cero. El botón usa GitHub Actions en su capa gratuita; la IA es un servicio público sin clave y, si ninguno responde, se activan las claves gratuitas que hayas configurado (Gemini, Groq, OpenRouter…). Las APIs viven en el plan Hobby de Vercel.

APIs de este taller

Todas viven bajo la misma dirección, cada una en su ruta. Cada fila enlaza a su API, su documentación y su documento OpenAPI.

APIs públicas sin clave

El taller aprovecha servicios públicos que no piden clave ni registro: normaliza países con REST Countries, monedas con Frankfurter y ciudades con Open-Meteo, y reúne un catálogo de APIs gratuitas descubiertas en el repositorio público public-apis/public-apis. Si una fuente no responde, no pasa nada: el valor se guarda tal cual.

Ejemplos de uso

Listar los datos de un recurso

curl https://TU-SITIO.vercel.app/api/ejemplo-notas/notas

Crear un registro

curl -X POST https://TU-SITIO.vercel.app/api/ejemplo-notas/notas \
  -H "Content-Type: application/json" \
  -d '{"titulo":"Mi primera nota"}'

Ver las rutas de una API

curl https://TU-SITIO.vercel.app/api/ejemplo-notas

Documentación y OpenAPI

curl https://TU-SITIO.vercel.app/api/ejemplo-notas/openapi.json

O abre la vista con /docs?api=ejemplo-notas.

Guardar cambios necesita una clave

Las lecturas funcionan siempre. Para crear, actualizar o borrar, pega la clave GITHUB_PAT en Vercel: los datos se guardan como archivos dentro de data/ en tu propio repositorio, sin base de datos de pago. Si generaste la API con token, añade Authorization: Bearer TU_TOKEN.

Proteger una API con token

curl -X POST https://TU-SITIO.vercel.app/api/mis-notas/notas \
  -H "Authorization: Bearer TU_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"titulo":"Una nota privada"}'
