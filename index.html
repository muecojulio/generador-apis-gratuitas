Elige una chispa creativa o diseña desde cero

Mesa de Forja

Define la ruta, añade bloques con un clic y ajusta la seguridad.

⚙️ Límites, modo solo lectura y token SHA-256 (opcionales)

El token se muestra una sola vez al terminar; guárdalo. Si vuelves a generar una API protegida sin marcar la casilla, se le quita la protección. El archivo de datos no puede pasar de 512 KB.

🔑 Clave del taller (opcional · GENERADOR_SECRETO)

Si en Vercel definiste la variable GENERADOR_SECRETO, escribe aquí ese mismo valor. Si no la definiste, déjalo vacío.

Vista previa

Mientras escribes, el motor del taller dibuja tus tablas, tipos, rutas HTTP y un registro JSON de muestra en tiempo real, sin enviar nada a ningún servidor.

Cadena de Inteligencia

Motores de IA gratuitos

/api/proveedores ↗

El taller intenta primero los proveedores públicos que no piden clave y, si ninguno responde, pasa a las claves gratuitas configuradas o al lector determinista incluido.

1. LLM7 (sin clave) 2. Kilo Gateway 3. OVHcloud AI 4. Pollinations 5. Lector incluido

Seguridad por diseño

  • ✔ Cero ejecución de código IA: la IA solo propone un esquema JSON validado; el motor de rutas está fijo y auditado en el repositorio.
  • ✔ Caché ETag + Índices O(1): búsquedas sin acentos y lecturas con 304 Not Modified.
  • ✔ Protección anti-abuso: verificación CSRF, límite de cuerpo, cupos por IP y comparación de tokens SHA-256 en tiempo constante.
