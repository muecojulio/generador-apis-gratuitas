Política de privacidad

Este taller es un proyecto de código abierto que publica APIs dentro de un repositorio. La regla de oro: cuantos menos datos, mejor. No hay cuentas, no hay cookies de seguimiento, no hay analítica y no se pide ningún dato personal para usar la página.

Última actualización: 25 de octubre de 2026.

1. Quién es el responsable

El proyecto generador-apis-gratuitas se mantiene en GitHub. Si despliegas tu propia copia en Vercel, tú eres el responsable del tratamiento de esa instalación. Para la instancia pública de demostración, el contacto es el repositorio (issues) y la dirección indicada en SECURITY.md.

2. Para qué se usan

Solo para prestar el servicio: generar el plano de tu API, guardarlo en el repositorio, publicarlo, documentarlo y proteger el taller del abuso. La base legal es tu consentimiento al enviar el formulario y el interés legítimo en mantener el servicio seguro y disponible. No hay perfilado ni venta de datos.

3. Qué datos se tratan

  • Lo que escribes al crear una API. El nombre de la ruta y la descripción (tablas, campos y reglas). Se envían a GitHub Actions para generar el plano y a un proveedor de IA gratuito. No escribas datos personales, contraseñas ni información confidencial en la descripción.
  • Los datos de las APIs publicadas. Viven en archivos data/<api>.json dentro del repositorio. Si el repositorio es público, esos datos también lo son.
  • Tokens de acceso. Se generan en tu navegador y solo se guarda su huella SHA-256 (64 caracteres). El token en claro se muestra una vez y no se envía al repositorio.
  • Datos técnicos mínimos. Vercel registra la petición HTTP para servirla y proteger el servicio. Los contadores de cupo del taller son en memoria y se olvidan en minutos.

4. Terceros que intervienen

Servicio Qué recibe Para qué
GitHub Nombre y descripción de la API; contenido de los datos Repositorio y ejecución del flujo de creación
Vercel Peticiones HTTP (IP, fecha, ruta, agente) Alojamiento y funciones serverless
Modelos de IA gratuitos La descripción escrita (LLM7, Kilo, OVHcloud, Pollinations o respaldo) Convertir la descripción en un plano JSON
Fuentes públicas sin clave Solo el valor de un campo pais, moneda o ciudad Normalizar ese valor (REST Countries, Frankfurter, Open-Meteo)
GitHub (public-apis) Nada tuyo: solo se lee su catálogo público de APIs Mostrar ideas de APIs sin clave

5. Almacenamiento y Retención

No se usan cookies. Los planos y datos se conservan mientras existan en el repositorio. Si una API define retencionDias, los registros más antiguos se descartan automáticamente.

6. Tus derechos y Seguridad

Puedes ejercer tus derechos de acceso, rectificación o borrado abriendo un issue en el repositorio. Para avisos de seguridad privados, consulta SECURITY.md.
